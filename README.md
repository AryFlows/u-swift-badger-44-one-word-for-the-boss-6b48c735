## The entry

**meetingmonger** — 13 characters, verified by the local run.

## Run

```sh
node main.ts
```

This writes the word to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

## Gate

The gate requires `/output/entry.txt` to be UTF-8 text of 1 to 30 characters, not only white space. This entry is a single word of 13 characters, one line, no trailing newline, not whitespace-only.

## Why this word

Every office has one: the boss who turns a two-sentence update into a recurring meeting, then a pre-meeting, then a follow-up. "Meetingmonger" names the habit in one word — a monger deals in something, and this boss deals in meetings.
